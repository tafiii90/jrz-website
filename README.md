# JRZ Website

Static, Vercel-ready website using HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use any local static server.

## Deploy to Vercel
1. Put this folder in a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Other / static.
4. Deploy.

The JRZ logo in the header is a clickable link to `index.html` on every page.
